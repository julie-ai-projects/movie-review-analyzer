# 🎬 Movie Review Analyzer

Analyze movie reviews using **AI and NLP**!  
This interactive app uses a multilingual **BERT** model from Hugging Face to detect sentiment in text and visualize results.

---

## 🚀 Features
- 🌍 Multilingual text sentiment analysis
- 🤖 Built with Hugging Face Transformers
- ⚡ Interactive UI powered by Gradio
- 💾 CSV export for results

---

## 🧠 Tech Stack
| Tool | Description |
|------|--------------|
| 🧩 **Transformers** | Pre-trained BERT model for sentiment |
| 🔥 **Torch** | Backend for deep learning |
| 💬 **Gradio** | Interactive web interface |
| 🐍 **Python** | Core logic and data handling |

---

## 💡 Example
| Input | Output |
|-------|---------|
| “The movie was too long but visually stunning.” | ⭐ **4 stars** |
